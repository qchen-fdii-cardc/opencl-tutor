# tasks_fsharp

F# OpenCL task track implemented with Brahma.FSharp.

This folder mirrors the 14 learning tasks and also includes a standalone device report task.

## Build all

`powershell
dotnet build .\OpenCL.Tasks.FSharp.slnx
`

## Run one task

`powershell
dotnet run --project .\03_vector_add_kernel\03_vector_add_kernel.fsproj
`
